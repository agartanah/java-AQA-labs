Для работы с проектом для начала нужно перейти в его папку.
Далее, смотря что вам необходимо:

1. Как собрать

```bash
mvn package
```

2. Как прогнать тесты

```bash
mvn test
```

3. Как запустить

```bash
java -cp target/classes app.Main
```

поменять имя можно в файле app.properties папки resources.
